Run your strategy

Everything you need to take a strategy from the report to a running bot, in five steps.

On this page 1 Create a Binance account 2 Install Python 3 Install the package 4 Set your API keys 5 Run your bot
1

Create a Binance account

Your bot places real orders through Binance, so you'll need an account and an API key pair before anything else.

  • Sign up at binance.com and complete identity verification.
  • Go to Account → API Management and create a new API key.
  • Save the API Key and Secret Key somewhere safe — the secret is only shown once.
⚠️ Never share your Secret Key or commit it to a file, repo, or chat. Treat it like a password.
💡 If you want to test without risking funds, enable a Binance Futures Testnet account instead and use testnet keys for now.
2

Install Python

You'll need Python 3.10 or newer installed on your machine.

  • Download it from python.org/downloads.
  • On Windows, tick "Add python.exe to PATH" during install.
  • Confirm it worked by opening a terminal (PowerShell on Windows) and running:
python --version
3

Install the package

Install the strategy package with pip:

pip install multistrategygenerator
4

Set your API keys

Your bot reads your Binance credentials from environment variables — this keeps them out of your code. In PowerShell, run:

$env:BINANCE_API_KEY="Your_api_key" $env:BINANCE_API_SECRET="Your_secret_key"

Replace Your_api_key and Your_secret_key with the values from Step 1.

⚠️ These environment variables only last for your current terminal session. Set them again each time you open a new terminal, before running your bot.
5

Run your bot

In the Strategy Report, use the Code button on any strategy row to download its Python file. Then, in the same terminal where you set your keys, run it:

python filename.py

For example, if your downloaded file is:

file main_ethusd_15m_52b791ff.py

you would run:

python main_ethusd_15m_52b791ff.py
✓ Press Enter and your strategy starts running, polling live prices and placing trades according to its rules.
